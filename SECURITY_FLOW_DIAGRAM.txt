╚══════════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────────┐
│  TẠI SAO CẦN CUSTOM?                                                        │
│                                                                              │
│  Spring Security KHÔNG BIẾT cách lấy user từ database của bạn!              │
│  → Bạn phải tự viết logic này                                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  CUSTOM Ở ĐÂU?                                                              │
│                                                                              │
│  File: service/UserDetailCustorm.java                                       │
│                                                                              │
│  @Service  ← Đăng ký với Spring                                             │
│  public class UserDetailCustorm implements UserDetailsService {              │
│      @Override                                                               │
│      public UserDetails loadUserByUsername(String username) {                │
│          // ⭐ ĐÂY LÀ PHẦN BẠN TỰ VIẾT                                       │
│          // 1. Lấy user từ database                                         │
│          User user = userService.hanldeUser(username);                       │
│                                                                              │
│          // 2. Kiểm tra user có tồn tại không                                │
│          if (user == null) {                                                 │
│              throw new UsernameNotFoundException(...);                        │
│          }                                                                   │
│                                                                              │
│          // 3. Trả về UserDetails cho Spring Security                        │
│          return new User(                                                    │
│              user.getUserName(),                                             │
│              user.getPassWord(),  // PHẢI mã hóa BCrypt!                    │
│              [ROLE_USER]                                                     │
│          );                                                                  │
│      }                                                                       │
│  }                                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  CHÈN VÀO BƯỚC NÀO?                                                         │
│                                                                              │
│  Bước 4 trong luồng xử lý:                                                  │
│                                                                              │
│  1. AuthenticationManager nhận request                                       │
│  2. → Gọi UserDetailCustorm.loadUserByUsername() ⭐                         │
│  3. → UserDetailCustorm gọi UserService                                      │
│  4. → UserService gọi UserRepository                                        │
│  5. → UserRepository query database                                          │
│  6. → Trả về UserDetails                                                    │
│  7. → Spring Security so sánh password                                      │
└─────────────────────────────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════════════════════════╗
║                          LƯU Ý QUAN TRỌNG                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Password trong database PHẢI được mã hóa bằng BCrypt
   → Nếu không, xác thực sẽ thất bại!

2. Secret key trong application.properties PHẢI giữ bí mật
   → Nếu lộ → Kẻ xấu có thể tạo token giả!

3. Token có thời hạn (24 giờ trong dự án này)
   → Hết hạn phải đăng nhập lại

4. UserDetailCustorm được Spring tự động tìm nhờ @Service
   → Không cần đăng ký thủ công trong SecurityConfiguration
